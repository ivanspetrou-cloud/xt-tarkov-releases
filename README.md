# XT Tarkov Overlay

Интерактивная карта квестов и оверлей для Escape from Tarkov. Здесь только готовые сборки для Windows, скачать их можно в разделе [Releases](../../releases).

## Как поставить

1. Скачайте `XT-Tarkov-Overlay.zip` из последнего релиза.
2. Закройте старую версию, если она запущена.
3. Распакуйте архив в любую папку и запустите `XT Tarkov Overlay.exe`.

Прогресс хранится в `%APPDATA%\XT Tarkov Overlay`, поэтому новая версия подхватывает его сама. Эту папку удалять не нужно.

## Важно

- Неофициальный проект, не связан с Battlestate Games. Escape from Tarkov, игровые материалы и названия принадлежат Battlestate Games.
- Сборка бесплатная, некоммерческая. Windows может показать предупреждение: программа пока не подписана.
- Карты и подложки: авторы tarkov-dev-svg-maps (Shebuka и др.), лицензия CC BY-NC-SA 4.0; тайлы Tarkov.dev и TarkovBOT.eu. Данные квестов: tarkov.dev. Скриншоты и тексты вики: Escape from Tarkov Wiki, CC BY-NC-SA.
